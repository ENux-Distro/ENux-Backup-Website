Patch Notes (For 6.0 Prototype): ENux is now switching bases from Debian to LFS. This provides a more minimal, flexible, and fully user controlled environment. Bedrock is going to be hijacked during installation to test compatability with LFS-based systems, which the results will be crucial for the development of The ENux Layer. This version of ENux does not implement The ENux Layer, it'll be integrated at the Alpha release of ENux 6.0. The brand new, custom CLI installer is going to follow cp / /target design. There isn't any XFCE or GUI in this version of ENux; it only has TTY/CLI. XFCE will be included in ENux 6.0 Stable.
